# GD Nova

Geode mod source project for Geometry Dash on Windows.

Features in alpha: NOVA button, live attempts/progress HUD, configurable HUD scale and visibility.

> Important: GD 2.281 compatibility is not verified. The workflow may fail until bindings/SDK support that game version.

Build: open **Actions** > **Build GD Nova (Windows)** > **Run workflow**. Successful builds produce the **GD-Nova-Windows** artifact.
