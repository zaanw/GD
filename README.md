# GD Nova v0.3

Interactive Midnight-style menu for Geometry Dash (Geode mod).

## Features

- NOVA button on main menu
- In-game toggle controls for HUD, attempts and progress
- HUD scale buttons, 0.25 to 0.90
- Geode-persisted settings
- Live attempt and completion HUD in levels

## Build

GitHub Actions builds automatically on push to `main`. Visit **Actions > Build GD Nova (Windows)** and download **GD-Nova-Windows** after a successful run.

**Target:** GD 2.2081 on Windows using Geode 5.11.2. Compatibility with GD 2.281 is unverified. Do not assume the binary is compatible with other versions.

**Not yet implemented:** Noclip, speedhack, hitbox viewer, macros. The menu is not a full cheat suite yet.
